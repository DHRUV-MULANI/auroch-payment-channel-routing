# Raw results

Store per-run CSV/JSON records and a configuration/metadata file here. Preserve the random seed, graph source and counts, capacity scale, workload count, amount source, routing method, elapsed time, and metric definitions. Keep generated records reproducible and do not commit large duplicate datasets.

`topology_summary.json` records graph properties. `single_payment_result.json` records one unseeded end-to-end run and is not a statistical experiment.
