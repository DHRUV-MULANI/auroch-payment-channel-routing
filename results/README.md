# Results

This directory is reserved for experiment outputs. Keep source inputs and scripts elsewhere.

- `raw/`: machine-readable per-payment or per-run records, configuration, and summaries.
- `plots/`: PNG/PDF figures with titles, units, legends, and experiment caveats.
- `quick_pilot/`: small, explicitly labeled exploratory multi-payment pilot with CSVs and metric plots.

Do not describe synthetic workload or proxy protocol results as a faithful reproduction of the paper. Include the input-data provenance and random seed with every run.
