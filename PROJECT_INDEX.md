# Project index

Start with this file for a map of the repository. For experiment assumptions and commands, see [docs/EXPERIMENT_PLAN.md](docs/EXPERIMENT_PLAN.md). Each data and output directory has its own README.

## Source files

| File | What it contains |
|---|---|
| `liquidity.py` | Current end-to-end single-payment Auroch simulation and liquidity audit. |
| `rreq.py` | RREQ route discovery. |
| `rrep.py` | RREP path propagation and completion. |
| `auction.py` | Auction message construction and reservation pricing. |
| `bidding.py` | Bid preparation and bidding rules; signature verification is currently a placeholder. |
| `auction_result.py` | Auction capacity allocation and validation. |
| `route_allocation.py` | Payment allocation over candidate routes. |
| `route_selection.py` | Route selection helpers and examples. |
| `directed_path.py` | Directed path/channel lookup helpers. |
| `payment.py` | Payment execution and directional liquidity updates. |
| `build_graph.py` | Builds a NetworkX multigraph from a Lightning snapshot. |
| `validate_graph.py` | Graph and channel data validation helpers. |
| `inspect_dataset.py` | Dataset inspection script; currently points at `data/`. |
| `requirements.txt` | Python package dependencies. |
| `README.md` | Project status, implementation summary, remaining work, and handover steps. |

## Data and generated outputs

- `lngraph_2021_11_27__00_00.json`: local Lightning snapshot at repository root (untracked, ~111 MB).
- `data/`: documented home for experiment inputs; see [data/README.md](data/README.md).
- `results/`: generated experiment data and figures; see [results/README.md](results/README.md).
- `results/quick_pilot/`: small proxy pilot outputs; see its README and `metadata.json` before interpreting its plots.
- `scripts/quick_eval.py`: runs the labeled exploratory multi-payment pilot; it does not implement the paper protocols.
- `scripts/full_experiment.py`: runs the full paper-sized parameter grid with explicit proxy methods; see [final_results/README.md](final_results/README.md) and its metadata before interpreting results.
- `final_results/`: consolidated delivery bundle with all generated topology and comparison plots, raw CSVs, configuration, and interpretation notes.
- `docs/`: experiment notes, reproducibility guidance, and current checklist; see [docs/README.md](docs/README.md).

## Current evaluation boundary

The checked-in implementation is a single-payment Auroch prototype. It is not yet an implementation of the full four-protocol paper comparison. Any result generated by an approximate or reduced-scale evaluator must name that method in its file and figure titles.
